# San Rigoberto — prototipo de red social

## Archivos
- `index.html`: estructura de la página.
- `style.css`: diseño adaptable a celular y computadora.
- `script.js`: interacciones de demostración.

## Cómo probar
Abre `index.html` en tu navegador. No requiere instalar nada.

## Qué funciona en este prototipo
- Diseño responsive para móvil y escritorio.
- Crear publicaciones en la página.
- Dar y quitar “Me gusta”.
- Abrir el formulario de comentarios y agregar comentarios.
- Buscar texto en las publicaciones.
- Simular confirmación/eliminación de solicitudes.
- Navegación demostrativa y avisos.

## Importante
Este es un prototipo front-end: las publicaciones y comentarios no se sincronizan entre personas ni hay cuentas reales, contraseñas, mensajería real o base de datos. Para convertirlo en una red social real hay que añadir autenticación, base de datos, almacenamiento de imágenes, reglas de seguridad y moderación.

## Publicar gratis con GitHub Pages
1. Crea una cuenta en https://github.com/ si no tienes.
2. Crea un repositorio nuevo, por ejemplo `san-rigoberto`.
3. Sube `index.html`, `style.css` y `script.js` a la raíz del repositorio.
4. En el repositorio entra a **Settings → Pages**.
5. En “Build and deployment”, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección tendrá una forma similar a `https://TU-USUARIO.github.io/san-rigoberto/`.

También puedes arrastrar los archivos a https://app.netlify.com/drop para una publicación rápida. Para una red social real, no publiques información privada ni pidas contraseñas en este prototipo.
